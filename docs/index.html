  2. 「Paint」をバーへドラッグ
  3. 描きたいページで押す

スマホでは「コピー」して、ブックマークの URL に貼る

操作

道具

  • S選択。囲むか押して選び、引くと移動、角で拡大縮小、Delete で削除、矢印で 1px（Shift で 10px）
  • Pペン（筆圧対応）
  • H蛍光ペン
  • E消しゴム（右クリック・ペンの消しゴム側でも）
  • L A R O直線・矢印・四角形・楕円（直線と矢印の端は、近くの線の端に吸い付く）
  • T文字（日本語入力対応）
  • F塗りつぶし
  • Iスポイト（描いた絵と文字から。対応するブラウザではページからも）

色と太さ

  • 1〜8色を選ぶ
  • [ ]太さ
  • Shift図形を 45° 刻み・正方形・正円に
  • Alt図形を中心から描く

編集

  • Ctrl+Z元に戻す
  • Ctrl+Yやり直す（Ctrl+Shift+Z でも）
  • Delete全消去（元に戻せる）
  • Ctrl+SPNG で保存

表示

  • Vページ操作モード（ツールを選ぶと描画に戻る）
  • B背景を透明・白・黒に
  • D計測表示
  • ?この一覧
  • Esc隠す（ブックマークレットで再表示）

ボタンと文字

  • ペン・図形をもう一度ペンの種類（万年筆・筆・鉛筆）や図形を選ぶ
  • 文字を押すペンなどのままでも選んで動かせる。もう一度押すと書き直し
  • 文字の入力中Esc・Ctrl+Enter・外を押すと確定
  • Tab電卓が入りのとき、= で終わる行に薄く出た答えを書き込む（iPhone・iPad はスペース）
  • ツールバーどこを押しても、引けば動かせる
  • その他（⋯）全消去・背景・保存・コピー・電卓・画面に固定・デフォルトの変更
