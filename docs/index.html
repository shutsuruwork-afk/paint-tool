ペイント
ブックマークレット

開いているページの上に、そのまま描けるペイントツールです。ブックマークを押すだけで起動し、拡張機能もアカウントも要りません。入力から線が画面に出るまでの遅延を減らす仕組みを、ブラウザが対応している限りすべて使います。

Paint ← このボタンをブックマークバーへドラッグ

試し書き

「このページで試す」を押して、下の文の誤字を赤ペンで丸く囲んでみてください。

ブックマークレッドは、ブラウザのブックマークに保存して使う小さなプログラムです。

太さは [ ]、取り消しは Ctrl+Z、隠すときは Esc。D を押すと、入力 1 件の処理時間や使われている機能がその場で表示されます。

入れ方

  1. ブックマークバーを表示します。Chrome・Edge・Firefox では Ctrl+Shift+B、Mac では ⌘+Shift+B です。
  2. 赤い「Paint」ボタンを、ブックマークバーへドラッグします。
  3. 描きたいページで、追加したブックマークを押します。もう一度押すと、絵を残したまま隠れます。

スマートフォンなどドラッグできない環境では、「コードをコピー」を押してから適当なページをブックマークし、そのブックマークの URL 欄をコピーした内容に書き換えて保存します。

このブラウザで使える低遅延機能

いま開いているブラウザで判定した結果です。使えない機能は、自動的に代わりの方法へ切り替わります。

機能状態役割

計測

3,000 点のペン入力（筆圧あり）を流し込み、メインスレッドが塞がる時間を測りました。この時間が短いほど、次の入力をすぐに受け取れます。

項目1920×1080 @1x@2x（3840×2160）
入力 1 件の処理4〜7 µs5〜7 µs
ストロークの確定1〜3 ms2〜11 ms
元に戻す2〜5 ms3〜17 ms
長い斜め線の履歴メモリ外接矩形の 24%外接矩形の 12%
背景の塗りつぶし約 50 ms約 170 ms
起動20〜36 ms

60 Hz の 1 フレームは約 16,700 µs です。毎回パス全体を描き直す素朴な実装は、同じ条件で 1 件あたり 60〜90 µs かかり、点が増えるほど遅くなります。本ツールの処理時間は点の数によらず一定です。計測はヘッドレス Chromium 141 とソフトウェア GPU（SwiftShader）で行いました。確定・元に戻す・塗りつぶしは GPU 処理の比重が大きいので、GPU のある実機ではこれより短くなる見込みです。npm run bench で再計測できます。

遅延を減らす仕組み

  • 入力は pointerrawupdate で受け取った瞬間に描き、pointermove とはタイムスタンプで重複を除きます。間に挟まった点も getCoalescedEvents ですべて拾います。
  • 描いている途中の線は、新しい点の分だけを追記します。毎回パス全体を描き直さないので、線が長くなっても重くなりません。
  • 半透明の線は不透明で描き、レイヤごと不透明度をかけます。線が自分と重なっても濃くなりません。
  • 確定と元に戻すは、線が通った 128px 四方のタイルだけを GPU 上でコピーします。全画面の getImageData は使いません。
  • 消しゴムは、削る直前のタイルだけを退避します。消し始めに画面全体をコピーする待ち時間がありません。
  • キャンバスの確保や合成処理の初回コストは、起動直後のまだ描いていない時間に済ませます。
  • 塗りつぶしは描いた範囲だけを読み戻し、塗る範囲を矩形パスにまとめて GPU に 1 回で塗らせます。
  • 筆の大きさを示すカーソルは CSS カーソル画像なので、OS が遅れなく描きます。
  • UI は Shadow DOM と CSSOM だけで組むので、ページの CSS、CSP の style-src、Trusted Types の影響を受けません。

できないこと

  • Chrome と Edge は、CSP が厳しいサイト（GitHub など）ではブックマークレットの実行自体を止めます。Firefox は CSP に関係なく実行します。
  • 絵は画面に固定されます。ページをスクロールしても絵は動きません。ページを操作したいときは V で操作モードにします。
  • 保存される PNG は描いた絵だけです。下にあるページは写りません。
  • 埋め込み表示（iframe）のページでは、PNG の保存やクリップボードへのコピーがブロックされることがあります。
