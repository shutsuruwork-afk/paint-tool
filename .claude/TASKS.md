### T-005 設定を覚える: インストールページで選んだ既定で始まり、サイトごとに変えた所を覚える
- 状態: 次
- 目的: 起動するたびに色や太さ、ツールバーの位置を選び直す手間をなくす。文字に触れるなどの動きを、好みで選べるようにする（R-004 で C に決定、ideas/touch-text.md）
- 完了条件:
  - [ ] インストールページで、色・ペン / 蛍光ペン / 消しゴムの太さ・文字の大きさ・ツールバーの位置・「文字に触れる」を選ぶと、その設定入りのブックマークレット（ボタン・コピー・このページで試す）になる。ページを開き直しても選んだ設定が残る
  - [ ] そのブックマークレットで、どのサイトでも選んだ設定で始まる
  - [ ] サイトで色・太さ・濃さ・ツール・ツールバーの位置を変えると、次にそのサイトで開いたときはその続きから始まる。ページの localStorage に書くのはキー 1 つだけ
  - [ ] 背景・ページ操作モード・計測表示は覚えない
  - [ ] localStorage が使えないページでも、エラーにならずに既定で動く
  - [ ] 上記をテストに追加し、`npm test` が通り、`dist/`・`docs/` を再生成してコミットした
- 関連: `src/paint.js` の状態・UI 同期・起動、`src/install.html`、`build.mjs`、`test/helpers.mjs`（インストールページを配るルート）
- メモ:
  - 既定はコードの中の `'__PAINT_DEFAULTS__'`（JSON.parse される文字列）を置き換えて渡す。T-022 で読み込みと `touchText` は入れた。テストは helpers の `withDefaults(CODE, {...})` と `runCode` で試せる。
- メモ:
  - サイトをまたいで自動で共有する方法はない。ブックマークレットはページの中で動き、保存領域はサイトごとに分かれる。別のオリジンの iframe に保存しても、今のブラウザは第三者の保存領域をトップのサイトごとに分けるので共有されない。CSP の frame-src で iframe 自体も止められることが多い。
  - 覚えないもの（案）: 背景（白・黒のまま開くとページが見えず驚く）、ページ操作モード、HUD。
  - localStorage はサンドボックスの iframe などで例外を投げるので、読み書きは try/catch で包み、失敗したら覚えないだけにする。
