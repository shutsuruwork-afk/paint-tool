### T-003 絵をページに貼り付け、スクロールしても一緒に動くようにする
- 状態: 進行中
- 目的: 今は絵が画面に固定され、スクロールすると本文とずれる。注釈として使えるように、絵をページ側に貼り付ける（ideas/scroll-follow.md）
- 完了条件:
  - [ ] 描いてからページをスクロールすると、絵が本文と一緒に動く（スクロール済みの位置で描いた場合も同じ）
  - [ ] スクロール中に JS が動かない（scroll リスナーを使わない。タイルは文書の一部としてブラウザが動かす）
  - [ ] 端の近くに描いても、横スクロールバーが出たりページの高さが伸びたりしない
  - [ ] 元に戻す・やり直す・消しゴム・塗りつぶし・全消去・PNG 保存が、スクロールした位置でも正しく動く
  - [ ] html に位置ずれ（position: relative と margin など）があるページでも位置が合う
  - [ ] 確定の瞬間に線がちらつかない（半透明の線を含む）
  - [ ] 入力 1 件の処理時間が悪化しない（`npm run bench` で比較）
  - [ ] 上記をテストに追加し、`npm test` が通り、`dist/`・`docs/` を再生成してコミットした
- 関連: `src/paint.js` のキャンバスのサイズ管理・履歴・ストローク・タイル・塗りつぶし・書き出し、`test/`
- メモ:
  - 方式: 確定した絵を「面」（ページ座標に置いた 512px 四方の canvas タイル、必要な所だけ作る）に描く。面のホスト要素は documentElement 直下の absolute 配置で、contain: strict と overflow: clip で文書の大きさに切り詰める（はみ出してスクロール範囲を広げないため）。
  - 描いている途中の線（live / pred）は今までどおり画面に固定し、確定時に面へ移す。入力の経路は変えない。
  - 座標: V（画面のデバイス px）→ S（面の px）は S = V × (面の dpr / 現在の dpr) + (スクロール − 面の原点) × 面の dpr。ストローク開始時に一度だけ求める。
  - 履歴タイル（128px）の印は S 座標で付ける（文書が大きいので Set で持つ）。表示タイル 512 は 128 の倍数なので、履歴タイルが表示タイルをまたがない。
  - 表示タイルは desynchronized にしない（数が多いと低遅延用の経路が重い）。live は desynchronized なので、確定時に live を消すとタイルより先に画面へ出てちらつく。確定時は live を残したままグループを隠し、2 フレーム後に消す。
  - 範囲外: ページの中の一部だけがスクロールするサイト（Gmail など）、描画中のスクロール（開始時の位置に確定する）、本文があとから動くことによるずれ。
