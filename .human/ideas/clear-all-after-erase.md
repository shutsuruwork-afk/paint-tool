# 全消去に消す物があるかを、消しゴムで消し終わった後に確かめる

2026-10-16 のアイデア（チャットで受け取ったものを Claude が転記。research/simple ブランチのチェックポイント 3 で、全消去のボタンを「消す物がないときは薄くする」形にした流れで出た）

> 全消去に関して。消しゴムで消し終わった後に検証すれば、軽く済むんじゃない？もしこれが有用なら、メインの.human/ideaの部分にメモっておいて欲しい

---

## Claude のメモ

- 対応: T-084（候補）
- 有用か: 有用。ただし「消し終わった後に確かめる」だけだと、今の「全消去を押したときに確かめる」（T-063 の hasInk）と 1 回に読み戻す量は同じで、消しゴムはよく使うので合計ではむしろ増える。軽くなるのは、次の 2 つを組み合わせたとき。
  1. 消しゴムが触れたタイルだけを確かめる。描いた物があるタイルを覚えておき（線を確定したタイルは「ある」にする。これは読み戻し不要）、消しゴムを離したら、触れた 128px のタイルだけを読み戻して、空なら「ない」にする。「ある」タイルが 0 になったら、消す物がない。読み戻しは描いた範囲の全体ではなく、1 回の消しゴムで触れた分だけ（短い線なら数枚〜十数枚）で済む。
  2. 離した直後ではなく、手が空いたとき（requestIdleCallback）に確かめる。読み戻し（getImageData）は GPU の仕事が終わるのを待つので、離した直後にやると、すぐ次に描き始めた線が引っかかるかもしれない。
- 消しゴムのほかに、元に戻す・やり直す・選択の削除・全消去を元に戻す、でも画素が減ったり増えたりする。それぞれ、入れ替えた矩形のタイルだけを同じように確かめ直す（最初まで元に戻したときも、空と分かる）。
- 得られる物: 消す物がないときに、全消去を前もって薄くできる。research/simple のチェックポイント 3 は全消去がバーにあり「できないときは薄い」にしたが、今は「直前が全消去」か「描いた範囲が空」しか分からず、消しゴムで全部消した後や最初まで元に戻した後は濃いまま（押しても何もしない）。これが正しく薄くなる。
- 本家では: 全消去はその他のメニューの中で、薄くする見た目がない。押したときに確かめる今の形（T-063）と結果は同じなので、今は効き目がない。本家にも「消す物がないときは薄い」を入れるとき（メニューの全消去を薄くする、など）に一緒に入れるのがよい。
- 決めてほしいこと（2026-10-16 にチャットで回答: 入れるつもりで、先に試す）:
  - 本家の全消去にも「消す物がないときは薄い」を入れるか → 入れるつもり（T-084）
  - research/simple のチェックポイント 3（と最小構成 3）に先に入れるか → 先に試す

### 結果

- 試し: research/simple ブランチの T-085（2026-10-16）。チェックポイント 3 と最小構成 3 に入れた。描いた物があるかもしれない 128px のタイルを覚え（線を確定したタイルは読み戻さない）、消しゴム・元に戻す・やり直す・塗りつぶし・選択の後に、触れた・入れ替えたタイルだけを手が空いたとき（requestIdleCallback）に 1 枚ずつ読み戻す。消しゴムで全部消した後・最初まで元に戻した後に、全消去が薄くなる。
- 重さ（ヘッドレスの計測）: 手書き風の線を消しゴム 1 本で消すと、読み戻しは 1x で 8〜15 タイル・合計 0.6〜1.6 ms、2x で 21〜25 タイル・1.2〜3.1 ms（1 タイル最大 0.9 ms）。実機の GPU では未確認。
- 本家に入れるとき（T-084）: 全消去がメニューの中なので、薄くする見た目（メニューの全消去を薄くする）と一緒に入れる。実機で試してもらってからにする。
