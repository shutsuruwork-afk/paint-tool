# paint-tool

開いているページの上にそのまま描ける、ブックマークレット製のペイントツールです。
拡張機能のインストールは要りません。入力から線が画面に出るまでの遅延を減らす仕組みを、ブラウザが対応している限りすべて使います。

- 圧縮後 約 61 KB（gzip 約 25 KB）、外部リソースの読み込みなし
- 選択（移動・拡大縮小・削除）・ペン（筆圧対応。万年筆・筆・鉛筆にも切り替え可）・蛍光ペン・消しゴム・直線・矢印・四角形・楕円・文字（日本語入力対応）・塗りつぶし・スポイト
- 元に戻す / やり直す、PNG 保存、クリップボードへコピー、背景（透明・白・黒）、ページ操作モード、電卓（文字に書いた計算式の答えを出す）
- 絵はページに貼り付くので、スクロールしても本文と一緒に動きます。その他のメニューの「画面に固定」を入れると、スクロールしても画面の同じ所に留まります（動画や地図の上に描くとき）

## 入れ方

1. インストールページ **https://shutsuruwork-afk.github.io/paint-tool/** を開き、必要なら「デフォルトの設定」で色や太さを選んでから、赤い「Paint」ボタンをブックマークバーへドラッグします。
   同じページはリポジトリの `docs/index.html` にもあります。
2. 描きたいページで、追加したブックマークを押します。もう一度押すと、絵を残したまま隠れます。

ドラッグできない環境では、[`dist/bookmarklet.txt`](dist/bookmarklet.txt) の 1 行をそのままブックマークの URL 欄に貼り付けます。

## 使い方

ツールバー（幅 約 490px。タッチの画面ではボタンが大きく約 600px）には、よく使う物だけを並べています。左から、選択・ペン・蛍光ペン・消しゴム・図形・文字・塗りつぶし・色と太さ・元に戻す・やり直す・ページ操作・その他・隠す・閉じるです。1 段に収まらない幅（スマホなど）では、選択〜塗りつぶしの段と、色と太さ〜閉じるの段の 2 段に分けます。

- **ペン**は、ペンを選んだ状態でもう一度押すと、種類のパネルが開きます（ペン・万年筆・筆・鉛筆）。万年筆は線の向きで太さが変わり（右上がりは細く、右下がりは太い）、筆はゆっくりだと太く速いと細く、鉛筆は少しかすれます。選んだ種類はサイトごとに覚えます。
- **図形**は最後に使った図形（直線・矢印・四角形・楕円）を表示します。押すとその図形になり、図形を選んだ状態でもう一度押すと、4 つの図形を選べるパネルが開きます（ペンと同じ）。
- ペンと図形の選択肢を 1 回押しただけで出したいときは、インストールページの「デフォルトの設定」で選べます。
- **色と太さ**の点は、今の色・太さ・濃さを表します。押すと、パレット・カスタム色・スポイト・太さ・濃さのパネルが開きます。
- **その他**（⋯）には、全消去・背景・PNG 保存・クリップボードへのコピー・電卓と画面に固定の入り・切り・デフォルトの変更・Simple Preview があります。「デフォルトの変更」は、使っているブックマークの既定を読み込んだインストールページの設定を新しいタブで開きます（変えたら「Paint」ボタンをドラッグし直します）。
- **隠す**（−）を押すと、ツールバーも絵も隠れます（`Esc` と同じ）。画面の下に「ブックマークレットで再表示」と数秒出て、ブックマークレットをもう一度押すか「再表示」を押すと、絵も履歴もそのまま戻ります。
- パネルは、描き始めるか、パネルの外を押すか、`Esc` を押すと閉じます。
- スマホ・タブレットでは、2 本指で動かすとページがスクロールします（1 本目の指で描き始めた線などは残りません）。動かしたまま離すと、しばらく滑って止まります（滑っている間に画面を押すと止まります）。タッチの塗りつぶしと文字は、指を離したときに塗る・入力欄を出します。
- ツールバーは、どこを押しても引けば動かせます（ボタンの上からでも、4px 以上引けば移動になり、そのボタンは押されません）。色と太さのパネルは、開いたまま動かせます（インストールページの設定で、ほかのパネルも開いたままにできます）。

| キー | 動作 |
| --- | --- |
| `S` | 選択（囲むかクリックで選び、ドラッグで移動・角で拡大縮小。矢印キーで 1px〈`Shift` で 10px〉、`Delete` で削除、`Esc`・`Enter` で確定） |
| `P` / `H` / `E` | ペン / 蛍光ペン / 消しゴム（右クリック・ペンの消しゴム側でも消去）。ペンを選んだ状態でペンのボタンをもう一度押すと、ペンの種類（ペン・万年筆・筆・鉛筆）を選べる |
| `L` / `A` / `R` / `O` | 直線 / 矢印 / 四角形 / 楕円（`Shift` で 45° 刻み・正方形・正円、`Alt` で中心から） |
| `T` | 文字（クリックした所に入力。外を押すか `Esc`・`Ctrl`+`Enter` で確定。書いた文字は、どの道具でも押すと選べ、もう一度押すと書き直し） |
| `F` / `I` | 塗りつぶし / スポイト（EyeDropper 対応ブラウザ） |
| `1`〜`8` | 色 |
| `[` / `]` | 太さ |
| `Ctrl`+`Z` / `Ctrl`+`Shift`+`Z`・`Ctrl`+`Y` | 元に戻す / やり直す（Mac は `⌘` も可） |
| `Delete` | 全消去（元に戻せます。消す物がなければ何もしません） |
| `B` | 背景を透明・白・黒に切り替え |
| `V` | ページ操作モード（絵を残したままページをクリック・入力できる。ツールを選ぶと描画に戻る） |
| `Ctrl`+`S` | PNG で保存 |
| `D` | 計測表示（入力レート、1 件の処理時間、入力→描画の遅れ、使われている機能） |
| `?` | 操作とショートカットの一覧（もう一度 `?` か `Esc`、外を押すと閉じる。インストールページにも同じ一覧があります） |
| `Esc` | 隠す（ブックマークレットをもう一度押すと再表示） |

ツールバーの右端の × で閉じると、絵も消えます。押し間違えても、8 秒の間は画面の下の「元に戻す」・`Ctrl`+`Z`・ブックマークレットのどれかで、絵も履歴もそのまま戻せます。お知らせの × を押すと、8 秒待たずにすぐ閉じます。何も描いていなければ、すぐに閉じます。

選択ツールでドラッグして囲むと、中の描いた物（範囲に収まる文字も含む）が、余白を詰めた枠で選ばれます。描いた物をクリックすると、その物（線・図形・塗り）が選ばれます。重なっているときは、いちばん小さい物が選ばれます。枠の中をドラッグすると移動、角のつまみで縦横比を保ったまま拡大・縮小（`Shift` で比を保たない）、辺のつまみで片方向だけ伸び縮みします。移動・拡大縮小・削除は、それぞれ 1 手として元に戻せます。

文字は線とは別の「物」として置かれ、いつも線より手前に出ます。選択ツールでも、ペン・蛍光ペン・図形・塗りつぶしを選んでいても、文字を押すと文字だけが選ばれ、そのまま引けば動きます（文字の上ではカーソルが移動の形になります。この動きはインストールページの設定で切れます）。角のつまみで拡大・縮小すると文字の大きさそのものが変わるので、拡大してもぼやけません。四角で囲んだ文字と四角は、別々に選んで動かせます。選んだ文字をもう一度押す（ダブルクリックでも、文字ツールなら 1 回押す）と書き直せて、空にして確定すると消えます。書き直しても、今の道具と色は変わりません。消しゴムで文字をなぞると、その文字が消えます（なぞっている間は薄く見えます）。

文字は、入力中は本物の入力欄なので、日本語の変換もそのまま使えます。確定すると、入力欄と同じ位置・色・大きさで置かれます。入力中に色・大きさ・濃さを変えると、すぐに反映されます。入力欄の周りには見えない余白があり、文字の少し外を押しても確定せずにカーソルが動きます。書き直すときは、その文字の色・大きさ・濃さが今の設定になります。

**電卓**を入りにすると（その他のメニュー、またはインストールページの「デフォルトの設定」）、文字を打っている行が計算式のとき、行の後ろに答えが薄く出ます。`Tab` を押すと書き込まれます。答えの前後の空白は式の書き方に合わせます（「12*3」→「12*3=36」、「12 * 3」→「12 * 3 = 36」、「12*3=」→「12*3=36」）。答えが出ている間は、入力欄の点線の枠が答えまで囲みます。数字と `+` `-` `×` `÷` `*` `/` `^`（べき）`%`（百分率）`( )` が使え、全角でも書けます。かけ算・わり算はたし算より先、`^` は右から計算します。計算は自前で行い、`eval` は使いません。書き込んだ後でも、入力欄の中なら `Ctrl`+`Z` で取り消せます。

ページの入力欄に文字を打っている間は、ショートカットは反応しません。

### Simple Preview

その他の「Simple Preview」を押すと、絵と履歴はそのままで、シンプルな表示のお試し版になります（研究用の research/simple-cp2 ブランチで作ったチェックポイント 2 を移した物）。

- バーはペン（押すたびに消しゴムと入れ替わる）・文字・元に戻す・その他・閉じるだけです。ペンを選んでいるとき、ペンのボタンの地が今の色になります（明るい色では印が黒）。
- その他は全消去・8 色・本家に戻すで、開いたままツールバーを引いて動かせます。
- ペンはいつも普通のペン・太さ 5・濃さ 100% です（本家の種類・太さ・濃さに影響されません）。
- 押せるボタンのないお知らせは出さず、電卓はいつも入り、ページ操作モードはありません。閉じる（×）は絵を残したまま隠します。
- ほかの道具はキーで使えます（Simple Preview のバーにない道具〈選択・蛍光ペン・図形・塗りつぶし〉を選んだまま切り替えると、ペンになります）。
- その他の「本家に戻す」で戻ります。切り替えるとそのサイトで覚え、インストールページの「最初に出す版」でも選べます（Simple Preview にすると Paint ボタンの名前が「Paint Simple」になります）。

### 描いた絵の保存について

- 描いた絵は、そのタブのメモリの中にだけあります。ディスクには書きません。隠しても（`Esc`）、ツールバーをたたんでも（−）、メモリにあるだけで、タブを閉じるかページを移ると消えます。残したいときは PNG で保存するか、クリップボードにコピーしてください。
- 元に戻すための履歴は、画面 8 枚分の画素か 200 手を超えると、古い物から捨てます。絵そのものは、描いた所の分だけメモリを使います。
- サイトの保存領域に書くのは、次の節の設定（数百バイト）だけです。

### デフォルトの設定と、サイトごとの記憶

- インストールページの「デフォルトの設定」で、色・ペン / 蛍光ペン / 消しゴムの太さ・文字の大きさ・最初の道具・ツールバーの位置・最初に出す版（本家か Simple Preview）と、見た目（ツールバーの色を暗い・明るい・好きな色から、ガラス風にするか。既定は明るい色のガラス風。ガラスはぼかし方・強さ・地の濃さ・彩度を開発用に調整できる）、開発用（ツールの中の「見た目（開発用）」で、ツールバーの色とガラス、蛍光ペンの予測、半透明の線の描き方をその場で変える。描いた線の入力を録って書き出す）と、動き（文字に触れる・ペンと図形の選択肢を 1 回で出す・ツールバーを動かしてもほかのパネルも開いたまま・電卓）を選べます。選ぶと「Paint」ボタンの中身がその設定入りに変わるので、ドラッグし直してください。どのサイトでも、その設定で始まります。ツールの「その他 → デフォルトの変更」で、使っているブックマークの設定を読み込んだこの欄が開きます。
- 使ったサイトでは、そのサイトで変えた色・太さ・濃さ・道具・ツールバーの位置を覚え、次に開いたときはその続きから始まります。保存するのは「既定から変えた所」だけで、そのサイトの localStorage にキーを 1 つ（`paint-bookmarklet`）だけ書きます。何も変えていなければ書きません。
- 背景・ページ操作モード・計測表示は覚えません。localStorage が使えないページでは、覚えないだけで普通に動きます。

## 遅延と効率のための設計

### 入力

- **`pointerrawupdate`**: rAF に整列される `pointermove` を待たず、入力が届いた瞬間に描きます。リスナーは描画中だけ登録します（登録しているだけでコストがかかるため）。
- **`getCoalescedEvents`**: 1 フレームにまとめられた中間点をすべて使います。速く動かしても線が角張りません。
- **重複除去**: `pointerrawupdate` と `pointermove` の両方から同じ点が届くので、タイムスタンプと座標で重複を捨てます。どちらか一方しか届かない環境（Firefox など）でもそのまま動きます。
- **予測**: 入力ごとに、直近 32 ms の点に 2 次式を当てはめて速さ・曲がる速さ（角速度）・減速を求め、1 フレーム先までの弧の上に線を先に伸ばして、ペン先との隙間を埋めます（最大 40 px。急に曲がっているほど短くします）。実際に書いた線の録画で比べると、1 フレーム後のペン先とのずれは、予測なしの約半分でした。ブラウザの予測（`getPredictedEvents`）は pointermove でしか届かず、pointerrawupdate で先に描いた点より古い所から伸びるので、外れて消える線（ぴょこぴょこ）が多く、予測なしよりずれていました（開発用の「予測の方法: ブラウザ」で前の方式に戻せます。ブラウザの予測がない環境では、直近の速度から 12 ms だけ外挿します）。ポインタが止まると予測は縮み、40 ms たつと予測線を消します（パソコンが重くて入力が遅れて届いているときは、その遅れの分だけ待ちます。動いている途中に予測線が消えて先端が点滅しないように）。1 フレームの長さは描いている間の rAF の間隔から測り、重くてフレームが飛んだときは何フレーム分かで割ります（予測が長くなりすぎないように）。蛍光ペンもペンと同じです（インストールページの開発用で、蛍光ペンの予測を「必要な分だけ」〈丸い先端で 1 フレーム後のペン先に届かない分だけを曲がりに沿って予測し、点と点を直線でつなぐ〉や「なし」にもできます。`npm run pop` で先端の消える画素と隙間を測れます）。
- **Delegated Ink Trail**（Windows）: 次のフレームが出るまでの線を OS に描かせます。このときは推測の予測線は使いません。
- **イベントの遮断**: 描画中の入力はページ側のリスナー（解析スクリプトやドラッグ処理）へ渡さず、メインスレッドに余計な仕事をさせません。
- **パームリジェクション**: ペンで描いている間とペンを離してから 0.5 秒はタッチを無視します。タッチで描き始めた直後にペンが触れたら、タッチの線を破棄してペンを優先します。

### 描画

- **desynchronized キャンバス**: 画面合成の順番待ちをせずに描画結果を表示します（対応ブラウザのみ）。
- **3 つの層**: 面（確定した絵）、`live`（描いている途中の線）、`pred`（未確定の末尾と予測線）。描いている途中は新しい点の分だけを `live` に追記し、毎回パス全体を描き直すことはしません。`pred` は毎回その小さな範囲だけ消して描き直します。
- **半透明の線**: `live` に線の濃さで直接描きます。新しい部分は、その所を先に `destination-out` で抜いてから `lighter` で線の濃さで足すので、線が自分と重なっても濃くなりません（不透明で重ねてから濃さをかけるのと同じ計算）。`pred` も線の濃さで描き、描いた部分の形（覚えておいた区間）で `live` が覆っている所を抜きます。確定時は `live` をそのまま面に合成するので、表示と確定結果が一致します。描いている途中の線に CSS の不透明度をかけないので、不透明の線と同じ経路で画面に出ます（前は 2 枚をまとめた要素に不透明度をかけていて、半透明の線だけ先端がぴょこぴょこ見えていました。開発用の設定で前の方式にもできます）。
- **確定時のちらつき防止**: `live` は低遅延の経路で、面のタイルより先に画面へ出ます。確定時に `live` をすぐ消すと一瞬線が消えるので、タイルを更新したのと同じフレームで `live` を隠し、2 フレーム後に消します。
- **平滑化**: 中点を結ぶ二次ベジエで線を滑らかにします。筆圧は平滑化した値を 0.25px 単位に量子化し、同じ太さの区間を 1 回の `stroke()` にまとめます。
- **カーソル**: 筆の大きさを示す円は CSS カーソル画像なので、OS が遅れなく描きます（DOM で追従させると 1 フレーム遅れます）。

### ページへの貼り付け（スクロール追従）

- **面**: 確定した絵は、ページの座標に置いた canvas のタイル（約 256 CSS px 四方）に描きます。タイルは描いた所にだけ作るので、長いページでもメモリは描いた量に比例します。
- **スクロール中は何もしない**: タイルは文書の一部なので、スクロールではブラウザが合成だけで動かします。`scroll` や `wheel` のリスナーは登録せず、スクロール中に JavaScript は動きません。
- **入力の経路は変えない**: 描いている途中の線は画面に固定した `live` / `pred` に描き、確定時に面へ移します。画面と面の座標の対応はストロークの開始時に 1 回だけ求めるので、入力 1 件の処理は増えません。
- **ページを広げない**: 面は `contain: strict` と `overflow: clip` で文書の大きさに切り詰めます。端に描いても横スクロールバーが出たり、ページが伸びたりしません。
- **画面に固定**: 入れると、面をその時のスクロール位置のまま `position: fixed` にします。スクロール中に JavaScript が動かないのは同じです。切ると、今見えている位置のままページに付け直します（スクロールした分だけ、面の画素・元に戻すの履歴・文字をまとめてずらします。切る時だけ、描いた量に比例した時間がかかります）。

### 確定・履歴・消しゴム

- **タイル単位の差分**: 線が通った 128px 四方のタイルを、面の座標で描画中に記録します。確定と元に戻すはそのタイルだけを GPU 上でコピーします。全画面の `getImageData` は使いません。横長の細い線のように外接矩形の方が小さい場合は、外接矩形を使います。
- **アトラス**: 1 手分のタイルは棚詰めで 1 枚のキャンバスにまとめて保存します。元に戻すとやり直すは、どちらも「現在の画素と保存した画素の入れ替え」という同じ処理です。
- **消しゴムのコピーオンライト**: 消しゴムはタイルに初めて触れたときだけ、削る直前の画素を退避します。消し始めに画面全体をコピーする待ちがありません。退避用のタイルは使い回します。
- **履歴の上限**: 画面 8 枚分の画素数または 200 手のどちらかを超えたら、古い手から捨てます。
- **暖機**: キャンバスの GPU バッキングの確保や合成処理の初回コンパイルは数十 ms かかるので、起動直後のまだ描いていない時間に済ませます。

### 塗りつぶし

- 塗る範囲は見えている画面の中だけです。読み戻すのは、それまでに描いた範囲（＋1px）と画面が重なる部分だけで、それ以外は透明だと分かっています。読み戻しはタイルを 1 枚の一時キャンバスに集めてから 1 回で行い、表示用のタイルの GPU 描画を遅くしません。
- 判定表を 1 回の線形走査で作り、スキャンライン法で探索します。塗る範囲は矩形パスにまとめて GPU に 1 回で塗らせます（`ImageData` の転送なし）。
- 透明部分を塗るときは 1px 広げて線の背面に合成するので、線との間に白い隙間が残りません。

### 選択

- 囲んでいる間の枠は、描いている途中の線と同じ `live` に描きます（DOM の枠より 1 フレームほど早く画面に出て、押してすぐ、少し動かしただけで出ます）。離すと、つまみの付いた選択の枠になります。
- 選んだ中身は面の中の 1 枚のキャンバスに浮かせ、移動や拡大縮小の間は枠の位置と大きさだけを変えます。描き直さないので、大きな範囲でも 1 件あたり 20 µs ほどです。拡大縮小の見た目はブラウザが合成で行い、確定のときに 1 回だけ高品質の補間で描き込みます。
- 浮かせるときの読み戻しは、それまでに描いた範囲と重なる所だけを 1 回で行い、枠を中身の外接矩形に詰めます。
- 確定は「元の範囲」と「置いた範囲」の 2 つの矩形を 1 手として履歴に積みます。動かさずに確定したときは、履歴は増やしません。
- 細い線を選んでも枠は最低 24px にして、移動とつまみを押し分けられるようにしています。

### 文字

- 入力中はクリックした位置に本物の `<textarea>` を重ねるので、IME（日本語の変換）がそのまま使えます。入力欄のキー・入力・フォーカスのイベントはページへ渡さないので、ページのショートカットが反応しません。
- 確定した文字は、面の中の要素（DOM）として置きます。ページと一緒にスクロールし、拡大縮小は文字の大きさを変えて描き直すのでぼやけません。位置と大きさは CSS px の整数に丸めます。
- 入力欄・置いた文字・PNG 保存の `fillText` は同じ書体と同じ基線の計算（行の高さの中で上下中央、CSS px で丸める）なので、書き直しや保存で文字が動きません（1x・1.5x・2x、13〜48px で画素単位の一致を確認）。
- 消しゴムは、線分と文字の外接矩形の当たり判定（割り当てのない計算だけ）で触れた文字に印を付け、毎フレーム 1 回だけ薄く見せ、離したときに消します。文字を 30 個置いても、消しゴムの入力 1 件は 7 µs ほどです。
- 文字の追加・移動・拡大縮小・書き直し・削除は、画素と同じ履歴に「物と、もう一方の状態」の組として積み、元に戻すとやり直すは今の状態との入れ替えで済ませます。

### ページからの隔離

- Shadow DOM の中に UI を作り、ページの CSS から隔離します。ホスト要素の位置やサイズは `!important` のインラインスタイルで固定します。
- `innerHTML` は使わず、スタイルは CSSOM（`adoptedStyleSheets`）で当てます。CSP の `style-src` や Trusted Types を強制するページでも、コード自体は動きます。
- 対応ブラウザでは Popover の top layer に載せ、ページのモーダルや z-index に関係なく最前面に表示します。
- 2 回目の実行は表示・非表示の切り替えだけで、絵はそのまま残ります。閉じるボタン（×）を押すと、8 秒後にすべてのキャンバスとリスナーを解放します。

## 計測

`npm run bench` の結果です（ヘッドレス Chromium 141、ソフトウェア GPU〈SwiftShader〉、3,000 点のペン入力、メインスレッドが塞がる時間）。

| 項目 | 1920×1080 @1x | @2x（3840×2160） |
| --- | --- | --- |
| 入力 1 件の処理 | 5〜8 µs | 4〜14 µs |
| ストロークの確定 | 4〜9 ms | 8〜22 ms |
| 元に戻す | 2〜5 ms | 2〜18 ms |
| 長い斜め線の履歴メモリ | 外接矩形の 24% | 外接矩形の 12% |
| 背景の塗りつぶし | 50〜75 ms | 170〜180 ms |
| 起動 | 19〜33 ms | 15〜27 ms |

毎回パス全体を描き直す素朴な実装は、同じ条件で 1 件あたり 64〜137 µs かかり、点が増えるほど遅くなります。本ツールの処理時間は点の数によらず一定です。確定・元に戻す・塗りつぶしは GPU 処理の比重が大きいので、GPU のある実機ではこれより短くなる見込みです（未確認）。確定の時間には、初めて描く場所のタイルを作る時間が含まれます。

## できないこと

- CSP（ページが実行できるスクリプトを制限する仕組み）が厳しいサイトでは、ブラウザによってはブックマークレットの実行自体が止められることがあります。Chrome の GitHub では動くことを、実際に使って確かめています。
- ページの一部だけがスクロールするサイト（Gmail、Slack など）では、その部分のスクロールに絵が付いていきません。ページ全体のスクロールにだけ追従します。
- 描いている途中にスクロールすると、線は描き始めた時点の位置に確定します。
- 描いた後で本文の位置が変わる（画像の読み込みで下に押し出される、折りたたみを開くなど）と、絵と本文がずれます。
- 線や図形の選択は画素の単位です。囲んだ範囲（クリックで選んだ物の外接矩形）に重なっている別の線も、一緒に動きます。拡大すると少しぼやけます（縮小はきれいです）。文字は物なので、この制限はありません。
- 塗りつぶしは文字を壁として扱いません（文字の下にも塗られます）。
- 保存される PNG は描いた絵だけです。下にあるページは写りません。
- iframe に埋め込まれたページでは、PNG の保存やコピーがブロックされることがあります。
- LINE の中のブラウザは、ページがいちばん上のときに下へなぞると、ブラウザごと小さくします。ページからはこの操作を止められないので、LINE の中では、ツールを使う間ページをいちばん上から 1px 下げておきます。スクロールできないほど短いページでは、下へなぞるとブラウザが小さくなることがあります（LINE の設定の「LINE ラボ」→「リンクをデフォルトのブラウザで開く」で避けられます）。

## 開発

```sh
npm install
npm run build   # src/paint.js → dist/paint.min.js, dist/bookmarklet.txt, docs/index.html
npm test        # Playwright（Chromium）で 81 項目の動作テスト
npm run bench   # 性能計測
npm run pop     # 蛍光ペンの先端の「ぴょこぴょこ」（消える画素）と隙間の計測
npm run predict -- paint-input-*.json  # 録った入力で、予測の方法（なし・ブラウザ・曲がりに沿う・直線）ごとの、1 フレーム後のペン先とのずれ・外れた予測・消える線の長さを比べる。負荷の様子（フレームの間隔・入力が届くまでの遅れ・予測線の点滅）も出す
```

開発用（インストールページの「開発用の項目をツールの中に出す」）を入れると、その他に「入力を録る（開発用）」と「録った入力を書き出す」が出ます。録っている間は、ペン・蛍光ペンで描いた線ごとに、押す・pointermove・pointerrawupdate・離すと、その中の点（getCoalescedEvents）・ブラウザの予測点（getPredictedEvents）・フレームの時刻を、座標（CSS px）・時刻・筆圧・処理した時刻と一緒に録ります。書き出すと JSON（`paint-input-日時.json`）になり、版・UA・dpr・画面の大きさ・使える低遅延の機能が入ります（ページの URL は入りません）。

`main` へのプッシュで GitHub Actions（`.github/workflows/pages.yml`）がテストを実行し、通れば `docs/` を GitHub Pages に公開します。プルリクエストではテストだけを実行します。

| パス | 内容 |
| --- | --- |
| `src/paint.js` | 本体のソース |
| `src/install.html` | インストールページのテンプレート |
| `build.mjs` | 圧縮（terser）とブックマークレット URL・インストールページの生成 |
| `dist/` | 生成物（`paint.min.js`、`bookmarklet.txt`） |
| `docs/index.html` | 生成されたインストールページ |
| `test/` | 動作テストと性能計測 |

テストは、実際のブックマークレットと同じく `javascript:` URL へのナビゲーションで起動し、インストールページのボタンの中身、デフォルトの設定（インストールページで選んだ設定入りのブックマークレット）、サイトごとの記憶、線の途切れ、元に戻すの画素単位の一致、半透明の重なり、塗りつぶしの漏れ、筆圧、パームリジェクション、ページへのイベント漏れ、入力欄フォーカス時のショートカット、厳格な CSP + Trusted Types、リサイズ、PNG 保存、入力点の重複処理、閉じるの取り消し、電卓（答えの表示と Tab の書き込み、計算の順序、全角、式でない行、式に合わせた空白、答えまで囲む枠）、選択（囲む・クリック・移動・拡大縮小・矢印・削除・元に戻すの画素単位の一致・スクロール追従）、文字（日本語の入力、ページへのキーの漏れ、確定の方法、入力中の色の変更、スクロール追従、物としての移動・拡大縮小・書き直し・消しゴム・全消去・元に戻す、囲んで線と一緒に動く、ペンのまま文字に触れる・設定で切る）、ツールバーの幅とパネル（開閉・画面の端での向き）、スクロール追従（スクロール後の描画・元に戻す・塗りつぶし・消しゴム・PNG、端でページが伸びないこと、html に余白があるページ、確定時のちらつき、スクロールリスナーがないこと、@2x と表示倍率の変更）を確認します。

JavaScript で操作するための API も `window.__paintBookmarklet` に用意しています（`toggle` `show` `hide` `close` `destroy` `undo` `redo` `clear` `tool(name)` `color(hex)` `stats()` `pixels(x, y, w, h)`）。`tool(name)` には `select` `pen` `marker` `eraser` `line` `arrow` `rect` `ellipse` `text` `fill` を渡せます。
