# .human

あなたと Claude が、時間をずらしてやりとりするための場所です。

| 場所 | 書く人 | 中身 |
| --- | --- | --- |
| `ideas/` | あなた | 思いついたこと。1 件 1 ファイル |
| `requests.md` | Claude | あなたに判断してほしいこと、やってほしいこと |

## ideas/ の書き方

- 1 件ごとに `.md` ファイルを作ります。ファイル名は内容が分かる英数字にすると、URL やコマンドで扱いやすくなります（例: `text-box.md`）。
- 中身はメモ書きで構いません。理由や「ここは迷っている」も書いてあると助かります。
- Claude は次の作業の始めに読み、タスク（`.claude/TASKS.md`）に取り込みます。あなたの文章は書き換えず、ファイル末尾の「Claude のメモ」に、対応するタスクや検討した点を書き足します。

## requests.md への返事

- 各項目の「回答:」の後ろに書くか、チャットで伝えてください。短い一言で構いません。
- 【急ぎ】が付いたものは、それが決まるまで止まっている作業があります。
